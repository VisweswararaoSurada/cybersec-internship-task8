**Task:** Install and configure a free VPN extension in Google Chrome, connect to a VPN server, and verify traffic encryption.

## 🎯 Objective
Understand how VPN browser extensions work in Chrome, how to connect/disconnect, and how they help protect privacy and hide IP addresses.

---

## 🛠️ Steps Performed

### 1. Choose a VPN Extension
I selected **VeePN (Free Extension)** because:
- It is available in the **Chrome Web Store**.
- Provides free access with multiple server options.
- Quick setup and no system-wide installation needed.

---

### 2. Install Extension in Chrome
- Opened **Google Chrome**
- Searched for **VeePN**.
- Clicked **Add to Chrome** → Confirmed installation.
- VeePN icon appeared in the Chrome toolbar.

---

### 3. Create Account & Login
- Created a free VeePN account.
- Logged in directly through the Chrome extension popup.

---

### 4. Connect to VPN
- Clicked the **VeePN icon** in the toolbar.
- Selected a free server (e.g., **Singapore**).
- Switched **ON** the VPN.
- Status changed to **Connected**.

---

### 5. Verify IP Address
- Visited [whatismyipaddress.com](https://whatismyipaddress.com).
- **Before VPN:** My IP showed my local ISP in India.
- **After VPN:** IP changed to a 51.158.253.90 Amsterdam server provided by VeePN.
                
---

### 6. Test Browsing
- Opened `https://ibommatamil.com/` and other websites.
- Browsing worked normally.
- Observed a slight decrease in speed due to VPN encryption.

---

### 7. Disconnect VPN
- Toggled VPN **OFF** from the VeePN extension.
- Refreshed [whatismyipaddress.com] – IP returned to my real ISP address.

---

## 📊 Outcome
- Successfully installed and used the VeePN extension in Chrome.
- Verified that IP address changed after connecting.
- Browsing traffic was encrypted via VPN.
- Observed a small reduction in speed.
